# E-Commerce Return Analysis – Excel

## Project Overview

This project analyzes e-commerce sales and return data using Microsoft Excel.

The analysis focuses on sales performance, profitability, customer returns, return reasons, regional trends, payment methods, and delivery performance.

## Tools Used

- Microsoft Excel
- Pivot Tables
- Excel Formulas
- Data Cleaning
- Data Analysis
- Dashboard & Data Visualization

## Project Workflow

1. Raw Data
2. Data Cleaning
3. Analysis
4. Dashboard Creation
5. Business Insights

## Key KPIs

- Total Orders: 34,500
- Total Sales: 5,865,293
- Returned Orders: 1,903
- Return Rate: 5.52%
- Net Sales: 5,476,537
- Total Profit: 970,019
- Average Order Value: 170.01
- Total Refund Value: 388,756

## Key Insights

- Electronics generated the highest sales among product categories.
- Electronics had the highest return rate among the analyzed categories.
- Fashion had a relatively higher return rate compared with several other categories.
- "Not as described" was the leading return reason.
- The East region recorded the highest regional return rate.
- Average delivery time was approximately 4.8 days.

## Business Recommendations

- Improve product descriptions and product images.
- Strengthen quality control processes.
- Investigate products with higher return rates.
- Monitor regional return patterns.
- Track return rates on a monthly basis.
- Improve product sizing information where applicable.
